# Problems
# 1. Sum of Two Numbers

## Problem Statement

Given two integers **A** and **B**, write a C program to calculate and print their sum.

## Input

A single line containing two integers **A** and **B**.

## Output

Print the sum of **A** and **B**.

## Constraints

-1000 ≤ A, B ≤ 1000

## Example 1

**Input**

```text
5 10
```

**Output**

```text
15
```

## Example 2

**Input**

```text
-7 20
```

**Output**

```text
13
```

## Sample File Name

```text
addition.c
```

**Difficulty:** Easy

**Topics:** Variables, Input/Output, Arithmetic Operators
