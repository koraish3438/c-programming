# Problems
# 1. Sum of Two Numbers

## Problem Statement

Given two integers **A** and **B**, write a C program to calculate and print their sum.

## Input

A single line containing two integers **A** and **B**.

## Output

Print the sum of **A** and **B**.

## Constraints

-1000 ≤ A, B ≤ 1000

## Example 1

**Input**

```text
5 10
```

**Output**

```text
15
```

## Example 2

**Input**

```text
-7 20
```

**Output**

```text
13
```

## 2. Celsius to Fahrenheit

### Problem Statement

Given a temperature in **Celsius (°C)**, convert it to **Fahrenheit (°F)** using the formula:

**F = (C × 9 / 5) + 32**

Print the result rounded to **2 decimal places**.

### Test Case 1

**Input**

```text
25
```

**Output**

```text
77.00
```

### Test Case 2

**Input**

```text
0
```

**Output**

```text
32.00
```

### Test Case 3

**Input**

```text
37.5
```

**Output**

```text
99.50
```
## 3. Leap Year

### Problem Statement

Given a year, determine whether it is a **Leap Year** or not.

A year is a leap year if:

* It is divisible by **400**, or
* It is divisible by **4** but not divisible by **100**.

Print `Leap Year` if the given year is a leap year; otherwise, print `Not a Leap Year`.

### Test Case 1

**Input**

```text
2024
```

**Output**

```text
Leap Year
```

### Test Case 2

**Input**

```text
1900
```

**Output**

```text
Not a Leap Year
```

### Test Case 3

**Input**

```text
2000
```

**Output**

```text
Leap Year
```
